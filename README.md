# Stock screener

Grades every US stock above $500M market cap against a personal investing mandate: moat, value (PEG),
EPS, EBITDA, debt, recent financing, falling-knife and new-company lenses, plus Fibonacci entry levels,
RSI, FMP's DCF value, Piotroski, Altman Z and the Magic Formula rank.

Data: Financial Modeling Prep (Starter). Storage and scheduled jobs: Supabase (shared with Life Ledger).
Site: Vite + React + Tailwind on Vercel. See CLAUDE.md for how it all fits together.

Not investment advice.
